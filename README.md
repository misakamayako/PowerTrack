# PowerTrack

**一个只活在你手机里的训练计划 / 训练记录 App。** 不用注册、不联网、没有广告和账号体系，
所有数据都写进本机 SQLite。训练中每个动作、每一组都是即时落库的，
所以关掉 App、杀进程、锁屏半小时回来，重开还能从「继续训练」接着练。

它要解决的是「计划」和「记录」之间的那道缝：计划说卧推 4×5、上斜 3×8，
训练时你实际可能只做了 3 组、还临时减重；两者分开存，但训练中必须能对上，
练完还要能回答「这周到底练了几次、比上个月重了多少」。

---

## 上手 30 秒

1. 安装 APK，看到首页（下一次计划 / 上次训练 / 本周进度）。
2. 「下一次计划」→ **制定计划** → 新建「推 A」→ 加卧推、上斜、侧平举，各加几组。
3. 回编辑器 → **排期** → 选「今天」。
4. 回首页 → 「下一次计划」显示「推 A」→ **开始这次训练**。
5. 点动作 → 调重量 / 次数 → **完成本组** → 休息倒计时 → 练完 **结束并保存**。

## 现在能做什么

### 先有一个计划

- 首页「下一次计划」卡里点 **制定计划** → 新建（如「推 A」）→ 加动作 → 给每个动作加组：
  组类型（常规 / 热身 / 递减 / AMRAP / 力竭）、重量或 **%1RM**、次数、组间休息。
- 动作从内置动作库里选，支持搜索、按肌肉 / 器械筛选。
- 计划可以改名、归档、删除，动作顺序能上下调整。

### 把计划排到某天

- 计划编辑器里点 **排期**，选今天 / 明天 / 本周一 / 下周一；排好后编辑页顶部会出现
  「已排期」卡片，首页的「下一次计划」也会同步显示。

### 开练（三种入口）

- **按排期开始**：首页「开始这次训练」，计划里的动作和组数会自动带进本次训练。
- **自由训练**：首页直接开一场空白训练，动作边练边加。
- **重复上次**：把上一次完成的训练整套复制成新的一场。

### 训练中

- 记一组只要「重量 → 次数 → 完成本组」，重量和次数都是大号步进器 + 自定义数字键盘，戴手套也能点。
- 支持递减组（一组里追加 `DROP →` 段）、热身 / AMRAP / 力竭标记、删除组后 **撤销**（保留最近 20 步）。
- 组间休息有倒计时横幅，可以跳过；到 0 自动收起。
- 结束训练会写入结束时间、算吨位、检测个人纪录；不想要这场就 **丢弃**，记录会被彻底删除。

### 练完看数据

- **历史**：每次训练的组数、吨位、时长、完成度；点进去看每个动作每一组的明细。
- **统计**：周吨位、单动作 e1RM 曲线、个人纪录（最大重量 / 同重量最多次数 / 最高 e1RM / 单次最高吨位）。
- **首页**：下一次计划、上次训练摘要、本周依从率（到练 / 计划）与完成组数。

### 设置与备份

- 训练日偏移（熬夜训练时把凌晨的记录算到前一天）、默认组间休息、体重。
- 一键导出纯本地 JSON 并复制到剪贴板。

## 动作库与素材

| 资源 | 数量 | 体积 | 用途 |
|---|---:|---:|---|
| `<exercise_id>.mp4` | 112 | 15.6 MB | 动作演示（静音、循环播放） |

## 技术栈

| 层   | 选型                                                                                             |
|------|--------------------------------------------------------------------------------------------------|
| UI   | Jetpack Compose（Material 3）+ 自建设计 token / 拇指区大按钮 / 步进器 / 数字键盘                 |
| 架构 | MVI（MVIKotlin 4.4）：每个页面对应一个 Store，Intent → Reducer → State / Label                   |
| 导航 | Navigation 3（`NavDisplay` + 可序列化 NavKey）                                                   |
| 存储 | SQLDelight 2.4（SQLite），JSON 列存可变规格（重量 / %1RM / 自重 / 力竭…）                        |
| DI   | Koin 4.2                                                                                         |
| 媒体 | Media3 ExoPlayer（asset 内视频）                                                                 |
| 构建 | Gradle 9.9.1 + AGP 9.4.1（内置 Kotlin）+ Kotlin 2.4.10，compileSdk 37 / targetSdk 36 / minSdk 26 |

工程按职责切分，`:app` 是唯一聚合点：

```
:app                       入口、Koin 装配、seed、导航装配
:core:model                纯领域模型（Kotlin/JVM，零 Android 依赖）
:core:domain               算法与仓储接口（Kotlin/JVM，零 Android 依赖）
:core:data                 SQLDelight schema、JSON 编解码、仓储实现、内置数据导入
:core:designsystem         颜色 / 间距 / 字号、按钮、步进器、数字键盘
:core:ui                   Store 生命周期桥接、格式化
:core:navigation           NavKey、NavDisplay 装配、底部导航
:feature:home              首页卡片（进行中 / 下一次计划 / 上次训练 / 本周进度）+ 排期列表
:feature:exercise-library  动作库（搜索 / 筛选 / 详情）与选动作
:feature:routine-editor    计划列表 / 编辑器 / 排期
:feature:workout           练中：动作列表 / 记录 / 递减组 / 休息 / 总结
:feature:history           历史列表 + 单次训练明细
:feature:stats             周吨位 / e1RM 曲线 / 个人纪录
:feature:settings          训练日偏移 / 默认休息 / 体重 / JSON 导出
```

## 测试

在 Android Studio 里跑也行（模块的 `test` 任务），命令行则是：

```powershell
.\gradlew.bat :core:domain:test :core:data:testDebugUnitTest `
               :feature:home:testDebugUnitTest `
               :feature:routine-editor:testDebugUnitTest `
               :feature:workout:testDebugUnitTest
```

当前 **89 个用例**，全部是纯 JVM 测试，不需要 Robolectric 或模拟器：

| 模块                     | 用例 | 覆盖内容                                                                                         |
|--------------------------|-----:|--------------------------------------------------------------------------------------------------|
| `core:domain`            |   30 | e1RM、有效容量、依从率、PR 检测、训练日归日、处方解析                                            |
| `core:data`              |   32 | 内存 SQLite 上的仓储行为（级联删除、排期回填、重复上次、seed 幂等与媒体文件存在性）、JSON 编解码 |
| `feature:home`           |    5 | 首页 Reducer                                                                                     |
| `feature:routine-editor` |   13 | 计划草稿编辑（槽位、组、排序、排期状态）                                                         |
| `feature:workout`        |    9 | 练中 Reducer、递减组重量推导                                                                     |
